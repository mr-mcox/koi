### Q3 — does convergent evidence narrow the Monte Carlo spread?

- **F36** — `src/screen/score/scorer.py:57-64` — **yes, already, by construction.**
  `_target_stats`: `half_width = 1 / sqrt(n + 1)`, where `n` is the sum of
  `provenance_weight` across every assertion filed against that target — more assertions
  (any provenance) strictly shrink `half_width` (verified numerically: 1
  `model_proposed` assertion → half_width 0.707; 2 → 0.577; 3 → 0.5; 5 → 0.408, all against
  the loaded `ScoringConfig`). This is a standard shrinkage-toward-the-mean estimator: `n`
  acts like an evidence count, `half_width` shrinks as `1/√n`, `mean` is pulled toward
  the (weighted) sample mean and away from the neutral prior.
- **F37** — decisions E1 (`demonstrated`) — this is deliberate and already measured against
  the failure mode the operator's intuition is reaching for: entering the *same* claim
  as multiple assertions (one per corroborating source) was tried and rejected — it
  double-counts correlated sources (n=3 same-claim gave +0.750 vs. honest n=2 +0.667).
  The fix already in place is `Citation.independent` — one assertion, many citations, each
  citation flagged independent-or-not — **not** filing distinct assertions for the same
  underlying fact. So "more evidence narrows spread" is already true, but *only* when each
  assertion is a genuinely distinct claim/angle on the dimension (operator's own framing:
  "distinct things showing different aspects") — filing the same fact twice to manufacture
  narrowing is the already-rejected bug, not a variant to build.
- **F38** — `src/screen/score/scorer.py:59-66` — `weight = config.provenance_weight[a.provenance]`
  is the only per-assertion multiplier feeding `n`; nothing today reads `Citation.independent`
  when computing `n` or `half_width` — E1's citation-level `independent` flag exists on the
  type (`screen/types.py`, `Citation`) but the Scorer's shrinkage math only ever sees
  provenance, not how many independent citations back a single assertion. Whether that's a
  gap (an assertion with 3 independent citations should shrink more than one with a single
  citation, same provenance) or intentional (assertion-level corroboration is supposed to
  be pre-resolved into `provenance` before it reaches the Scorer) is not stated anywhere in
  decisions.md/domain-model.md — open thread, not a finding.
